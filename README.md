# AR Infissi e Serramenti

Sito statico multipagina per AR Infissi e Serramenti, azienda con sede a Certaldo, provincia di Firenze.

Il progetto usa HTML, CSS e JavaScript puro. Non usa framework esterni e contiene una base ordinata pronta per essere estesa con immagini reali, contenuti definitivi, SEO locale e collegamenti operativi.

## Come aprire il sito

Apri `index.html` direttamente nel browser. Essendo un sito statico, non serve un server locale per la prima anteprima.

## Placeholder da sostituire

- Immagini SVG dentro `img/` con foto reali dei prodotti e delle realizzazioni.
- Telefono, email, WhatsApp, orari, dati aziendali e link privacy.
- Testi descrittivi definitivi, marchi trattati, dettagli tecnici e dati SEO.
- Iframe Google Maps nella pagina `contatti.html`.

## Prossimi sviluppi consigliati

- Collegamento modulo preventivo a email, WhatsApp o backend.
- Inserimento immagini reali ottimizzate.
- SEO locale per Certaldo e provincia di Firenze.
- Ottimizzazione mobile con test su dispositivi reali.
- Galleria realizzazioni filtrabile con immagini e categorie definitive.
- Pubblicazione online con dominio, hosting e monitoraggio performance.
